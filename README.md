# 帧研 AI HOT

帧研用于关注 AI 视频制作教程、工作流和模型更新，查看技术线索、原始出处及按周汇总的报告。

**[下载最新 Windows x64 安装包](https://github.com/NidhoggCYQ/AI-HOT-Releases/releases/latest/download/AI-HOT-Setup-x64.exe)** · [查看更新说明和 SHA-256](https://github.com/NidhoggCYQ/AI-HOT-Releases/releases/latest)

适用于 Windows 10/11 x64。安装后双击桌面的「帧研 AI HOT」，使用当前 Windows 账号进入。首次配置本地长视频分析组件约需下载 1.67 GB。外部模型的 API 密钥和费用预算可在应用设置中配置。

公开版自带 ComfyUI 官网订阅及 LTX-Video 发行记录，也可添加自己的关注。数据保存在本机。后续版本在应用内提醒，可阅读更新说明并直接下载，无需 GitHub 账号。运行安装程序前可核对发行页提供的 SHA-256。
